Comment ça marche

Cet espace sert à préparer le contenu du site sans écrire une ligne de code. Il fonctionne entièrement dans votre navigateur : rien n’est envoyé sur internet tant que vous ne publiez pas.

  1. SaisirAjoutez ou modifiez un bien, puis enregistrez. Vos modifications restent mémorisées dans ce navigateur, même si vous fermez l’onglet.
  2. TéléchargerCliquez sur « Télécharger le fichier à publier ». Vous obtenez un fichier nommé annonces.js (ou offres.js).
  3. PublierEnvoyez ce fichier à votre hébergeur, dans le dossier assets/data/ du site, en remplaçant l’ancien. Le site est à jour immédiatement.

Les photos

Envoyez d’abord vos photos dans le dossier assets/img/ du site, puis indiquez leur chemin dans le champ prévu, par exemple assets/img/2026-021.jpg. Un format paysage d’environ 1200 pixels de large convient. Sans photo, le site affiche une vignette neutre : l’annonce reste présentable.

Ce que la loi impose

Une annonce immobilière doit indiquer le prix honoraires inclus et préciser qui les supporte, afficher les classes DPE et GES du bien, et mentionner pour un lot de copropriété le nombre de lots, les charges prévisionnelles annuelles et l’existence éventuelle d’une procédure. Les champs correspondants sont prévus dans le formulaire : les renseigner suffit.

Bon à savoir

Cette page n’est pas protégée par un mot de passe et n’en a pas besoin : elle ne peut rien modifier sur le site en ligne, elle se contente de fabriquer un fichier. Tant que ce fichier n’est pas envoyé à l’hébergeur, le site public reste inchangé. Si vous souhaitez plus tard modifier le site directement depuis internet, sans manipulation de fichier, dites-le : cela suppose de passer par un hébergement de type Netlify avec une interface d’administration connectée.
